## Notas da versão v5.2.0

### Novidades
- Aviso em modal quando o app não está recebendo nenhum dado de telemetria ao clicar em "Telemetria Auto"

- Diversos ajustes na página inicial (landing page)

- Removidos arquivos não utilizados do self-updater do Windows (atualização silenciosa não é mais suportada)
